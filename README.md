# hayy-mushaf

ملفات المصحف اللي بيحمّلها تطبيق «حيّ» للصلاة على موبايل المستخدم لما يطلبها.
Mushaf files the Hayy prayer app downloads to the user's phone on request.

| Folder | Files | Source | Terms |
|---|---|---|---|
| `pages/` | `p001.png` … `p604.png` (604 pages) + `pages.tsv` (size and sha256 of each page) | King Fahd Glorious Qur'an Printing Complex — Madinah Mushaf (Hafs), green edition 1441 AH, PDF; each page cut from the PDF without any change | © King Fahd Glorious Qur'an Printing Complex, under the Complex's terms |
| `fonts/` | `QCF2001.ttf` … `QCF2604.ttf` (one font per page) + `QCF2BSML.ttf` (sura heads and basmala) | King Fahd Complex QCF fonts, v2 (1421 AH), as published in the public repository `nuqayah/qpc-fonts` | © King Fahd Glorious Qur'an Printing Complex — free use in software per the Complex's copyright page; not modified |

The files are kept exactly as received: no change to the text, the drawing or the fonts.
The rights belong to the King Fahd Glorious Qur'an Printing Complex; this repository only hosts the files for a free app.
